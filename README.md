# 纯前端

这是可独立部署的静态前端，不需要 Node.js。

1. 编辑 `config.js`，把 `API_BASE_URL` 改为 Python 后端地址（不要附加 `/api`）。
2. 本地运行 `./start.ps1`，浏览器打开 `http://127.0.0.1:5173`。
3. 部署时可把本目录完整上传到 Nginx、对象存储或任意静态托管平台。

若前后端同域并通过反向代理转发 `/api` 与 `/uploads`，将 `API_BASE_URL` 配置为空字符串 `""`。

访客默认只能浏览和留言；点击“管理员登录”并通过后端认证后，才会显示编辑控件。认证 Token 仅保存在当前浏览器会话中。
